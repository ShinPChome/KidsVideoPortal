```bash
pnpm build  # or npm run build / yarn build
pnpm preview
```

If you see **module not found** errors (e.g. lucide-react, sonner, etc.), run:

```bash
npm install lucide-react framer-motion class-variance-authority tailwind-merge sonner
```

Adjust `tailwind.config.js` and `src/index.css` as needed.
